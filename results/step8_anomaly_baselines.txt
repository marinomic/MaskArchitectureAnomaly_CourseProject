 How the ERFNet values were extracted
   The early entries in results.txt were written by an older script version that
   did not record the dataset name. Dataset attribution is inferred by cross-
   referencing the clearly labeled temperature-scaling entries at the bottom of
   the file (which DO carry dataset names). Specifically:
     - Road Anomaly appears labeled at four temperatures; its t=1.0 value was
       confirmed to be the 12.42 / 82.58 entry (appears twice).
     - RO-21 at t=1.308 is 2.86 / 67.21, consistent with the unlabeled t=1.0
       value 2.71 / 65.23 (temperature slightly raises both metrics).
     - FS Static at t=1.308 is 8.16 / 41.30, consistent with unlabeled 7.47 / 41.84.
     - RA-21 at t=1.308 is 0.00 / 0.00 (no valid OOD pixels in the 10-image subset).
     - FS L&F at t=1.308 is 0.00 / 0.00 (no valid OOD pixels with the correct
       label remapping). Earlier unlabeled entries show non-zero values for FS L&F,
       but these used an older label interpretation and are not reliable.

 ERFNet mIoU on Cityscapes val: NOT AVAILABLE. The eval/eval_iou.py script output
 was not saved to a results file. Re-run it to obtain this number.
