========================================================================
 STEP 5 - FINE-TUNING THE EoMT-COCO MODEL ON CITYSCAPES
 Task: semantic segmentation | Dataset: Cityscapes val (500 images)
 Evaluation resolution: 640x640 | Classes: 19 (Cityscapes train-ids)
========================================================================

GOAL
  The EoMT model trained on COCO (panoptic) is not specialised on road
  scenes. It is fine-tuned on the Cityscapes training set for semantic
  segmentation, and its improvement on the validation set is measured
  with the SAME evaluation pipeline used in Step 4.

TRAINING STRATEGY
  Phase 1 : prediction head only (backbone frozen)  - LR_head=5e-5
  Phase 2 : full fine-tune (whole network unfrozen) - LR_head=5e-5, LR_backbone=5e-6
  Optimizer : AdamW, weight decay 0.05
  Scheduler : 1000-step warmup + cosine decay (TOTAL_STEPS=20000)
  Mixed precision (AMP) : enabled

OBSERVATIONS
  - Fine-tuning recovers a lot on the typical road classes and on those
    that were near zero in COCO because of the class-space mismatch
    (e.g. pole, traffic sign, train, rider).
  - The fine-tuned version stays below the native Cityscapes checkpoint:
    expected, since it starts from a cross-domain base and uses limited
    training.
